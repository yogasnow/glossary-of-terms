# Музыкальные термины

[Визуальная карточка](music-glossary.png) помогает слушать музыку «по слоям».

| Термин | Первое объяснение |
|---|---|
| Высота звука | То, насколько высоким или низким воспринимается тон. |
| Тембр | Окраска звука, позволяющая различать инструменты и голоса. |
| Регистр | Часть диапазона — например, низкая или высокая. |
| Мелодия | Последовательность музыкальных звуков, воспринимаемая как линия. |
| Ритм | Организация длительностей и акцентов во времени. |
| Пульс | Ощущаемая регулярная доля. |
| Темп | Скорость движения музыкальных долей. |
| Размер | Способ группировки долей в такте. |
| Тоника | Опорный тон лада. |
| Модуляция | Переход в другую тональность. |

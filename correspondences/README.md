# Словарь соответствий · Python

Материал собран из учебных примеров Telegram-топика «Словарь соответствий». Это не дословная публикация переписки: названия, данные и код сведены в одну проверяемую структуру.

В Python `dict` хранит пары **ключ → значение**. Например, ключ `"питахайя"` ведёт к карточке с типом продукта и перечнем веществ. Цикл `for` перебирает записи, а `print()` выводит читаемые строки. [Открыть код `foods.py`](foods.py).

| Название в топике | Ключ в коде | Что сопоставлено |
|---|---|---|
| DRAGON FRUIT / питахайя | `dragon_fruit` | плод → вода, клетчатка, витамин C, магний, калий |
| Макадамия | `macadamia` | съедобное ядро → марганец, магний, медь, B1, E |
| Кокосовая вода | `coconut_water` | напиток → вода, углеводы, калий и другие минералы |
| Авокадо | `avocado` | мякоть → ненасыщенные жиры, клетчатка, калий, фолат |
| Семена чиа | `chia` | семена → клетчатка, АЛК, белок, минералы |
| Папайя | `papaya` | мякоть → витамин C, каротиноиды, клетчатка, фолат, калий |
| Миндаль, кешью, фисташки | `almond`, `cashew`, `pistachio` | орех → перечень питательных веществ |

## Запуск

```bash
python3 correspondences/foods.py
```

Файл использует только стандартный Python. Ввод — словарь `foods`, обработка — цикл по парам `key, value`, вывод — строки вида «продукт → вещества». Значения — учебные примеры, не количественный анализ состава и не обещания лечебного эффекта.

## Папайя на TypeScript

[Открыть `papaya.ts`](papaya.ts). Здесь `Record<string, Food>` — типизированный словарь: ключ `papaya` указывает на карточку плода. Внутри `nutrients` каждый ключ — вещество, а значение — его общая биологическая роль. `Object.entries()` превращает пары в строки для вывода. Проверка неизвестного ключа показывает, что отсутствие записи — отдельный случай, а не пустой состав.

```bash
node correspondences/papaya.ts
```

Ввод → карточка папайи. Обработка → поиск по ключу и перебор пар «вещество → роль». Вывод → читаемые соответствия. Код не измеряет состав конкретного плода и не делает выводов о лечении.

## Банан на TypeScript

[Открыть `banana.ts`](banana.ts). Как и у папайи, ключ `banana` ведёт к карточке продукта. `Record<string, string>` связывает вещества с их общей ролью, а `Object.entries()` перебирает пары.

```bash
node correspondences/banana.ts
```

Ввод → запись о банане. Обработка → перебор пар «вещество → роль». Вывод → строки соответствий и примечание о границах вывода.

# Glossary of Terms · словарь понятий

Открытый учебный словарь Снежаны: простые объяснения и короткие примеры кода для начинающих.

- [Музыка](music/README.md) — короткие определения с визуальной карточкой.
- [IT и программирование](it/README.md) — базовые понятия на примере учебного маршрута.
- [Словарь соответствий](correspondences/README.md) — записи из одноимённого Telegram-топика: продукты → состав, ключ → значение, ввод → обработка → вывод. [Рабочий пример на Python](correspondences/foods.py).

**Статус:** публичный учебный материал, не медицинская рекомендация. Описания состава продуктов качественные и зависят от сорта и порции. Повторное использование материалов требует отдельного разрешения; лицензия не указана.

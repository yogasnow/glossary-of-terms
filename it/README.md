# IT и программирование

| Термин | Первое объяснение |
|---|---|
| IT | Создание, хранение, передача и обработка информации с помощью цифровых систем. |
| Программа | Набор инструкций для компьютера. |
| Код | Текст инструкций на языке программирования. |
| Переменная | Имя для значения, которое программа использует и может менять. |
| Массив | Упорядоченная коллекция значений. |
| Функция | Именованное действие, которое можно вызвать. |
| Условие | Правило «если …, то …», выбирающее ветку действий. |
| Интерфейс | То, через что человек взаимодействует с продуктом. |
| Прототип | Ранняя версия для проверки идеи, а не обязательно готовый продукт. |
| Тест | Проверка ожидаемого поведения в конкретных условиях. |

Пример: в уроке из трёх карточек массив хранит карточки, переменная `index` показывает текущую, функции меняют шаг, а условия удерживают навигацию в границах.
